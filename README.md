# Random Trajectory CAPTCHA Demo

🔗 **Live Demo:** [https://gvenkatesh-12.github.io/react-random-trajectory-captcha-demo/](https://gvenkatesh-12.github.io/react-random-trajectory-captcha-demo/)

---

## 🎯 What is this?

A lightweight motion-based human verification challenge where users intercept an unpredictable, non-linearly moving orb inside a designated target area.

- **Default Difficulty**: Medium (with toggles for Easy and Hard)
- **Universal Device Support**: Touchscreens (iOS/Android), Mice, Stylus
- **Bot Resistant**: Real-time biometric telemetry scoring (`isLikelyBot` and `botConfidence`)
- **Automated Bot Solver**: Included for testing bot detection heuristics
